# Reporting a security issue

Send suspected CirclePy vulnerabilities privately to
[the maintainer](mailto:waleed9salah@gmail.com). Include the affected version or
commit, a minimal synthetic reproduction, expected behavior and possible impact.
Keep credentials, member data, cookies and signed URLs out of the report. Arrange
a secure exchange with the maintainer if sensitive evidence is necessary.

Please avoid public issues or pull requests containing exploit details before
the maintainer has assessed the report. You may report issues in any version;
`main` is the current development line, and this document does not announce a
new release. Release availability must be checked on the package index.

[Security boundaries and dependency review](docs/security.md) explains the SDK's
controls, caller responsibilities, current dependency risks and publishing gates.

Support is best effort; there is no guaranteed response time or backport window.
Main is the active development line, and the unreleased v1 documentation does not
extend the old 0.5.1 release's runtime support. See [support](SUPPORT.md) and
[maintainer guidance](docs/maintaining.md) for triage, version and release policies.
