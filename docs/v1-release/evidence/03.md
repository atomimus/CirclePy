## Changes and validation

Added `.github/workflows/ci.yml`: 15 uniquely named test jobs, `quality` and
`dependencies`. Pushes to main trigger them without PR/human-review gates.
Test jobs install the constrained dev extra, check dependencies, run all tests,
publish test/branch-coverage reports, verify frozen inventory/public signatures,
build from sdist and validate both installed artifacts outside the checkout.
Reports have fixed unique names and 14-day retention. A failing job fails CI;
there are no continue-on-error settings or ignored vulnerabilities.

Added reusable `http_server`, `api_payloads` and `async_session` fixtures. The
server checks method/path, independent JSON bodies and selected headers, records
requests and fails teardown on mismatches or unused expectations. Raw response
bytes cover malformed/empty JSON. New tests cover existing Headless bearer auth,
response pass-through, documented error JSON, malformed/empty fixture responses,
native async fixture I/O/cleanup and outbound connection/DNS rejection.
These supplement the existing 20 regression tests without changing production code.

Expanded the dev extra and regenerated `constraints-dev.txt` with uv 0.12.15:
77 requirements resolved universally, with platform/Python markers. Consumer
ranges/backend/version remain unchanged. The artifact validator checks consumer
dependencies/import locations before installing only the three constrained pytest
tools and running the full copied suite under `python -I`. Sdist includes the
fixture data, helpers and workflow policy inputs; wheel remains package-only.
