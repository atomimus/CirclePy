# Task Evidence

Implementation tasks create one NN.md file here only after the user starts that task. Record completion only after the task checks and main push are verified.

Each report records the task and selected base SHA, official sources/spec hashes and retrieval dates, decisions, actual code/documentation changes, executed validation commands and results, relevant compatibility implications, and remaining provider/access limitations. Redact credentials, tokens, signed URLs, private member data, and billing information.

Report final main commit SHAs and remote verification in the chat so a commit does not attempt to contain its own SHA. Verify prerequisites through origin/main history and current-commit check evidence before dependent work.
